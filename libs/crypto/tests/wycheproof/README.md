# Wycheproof vectors

Test vectors from [Wycheproof](https://github.com/C2SP/wycheproof), Apache
License 2.0 (`LICENSE`), at the commit in `COMMIT`. `tests/wycheproof.rs`
runs them through `aricode-crypto` (ADR 0066).

The files are the upstream ones with only the fields the test reads;
`tools/wycheproof-extract.py WYCHEPROOF_CHECKOUT` produces them again.
